# ai-daily-chatting

AI Daily Chatting — hệ thống prompt và tài liệu hỗ trợ hội thoại hằng ngày bằng tiếng Việt.

## Gemini

```text
gemini/
├── README.txt
├── gem/
│   ├── 00_INDEX_DAILY_CONVERSATION.pdf
│   ├── 01_NATURAL_CONVERSATION.pdf
│   ├── 02_DAILY_CHECK_IN.pdf
│   ├── 03_TOPIC_TRANSITIONS.pdf
│   ├── 04_CONVERSATION_STATE.pdf
│   ├── 05_GEN_Z_VIETNAMESE_CHAT_STYLE.pdf
│   ├── 06_PLAYFUL_CONVERSATION.pdf
│   ├── 07_EMOTIONAL_SUPPORT.pdf
│   ├── 08_CONVERSATION_REOPEN.pdf
│   ├── 09_STORY_SOCIAL_MEDIA.pdf
│   └── 10_CONVERSATION_ANTI_PATTERNS.pdf
│
└── instructions/
    ├── MASTER_CORE v3.0.txt
    └── README_v3.0.txt
```

## Structure

- `gemini/gem/` — bộ tài liệu kiến thức hội thoại.
- `gemini/instructions/` — prompt lõi và hướng dẫn sử dụng.
- `gemini/README.txt` — hướng dẫn tổng quan cho thư mục Gemini.
